🎓 StudentMitra – Student Management System
StudentMitra is a web-based Student Management System developed using Java, JSP, Servlets, JDBC, and MySQL. It is designed to help educational institutions manage students, departments, courses, assignments, attendance, marks, announcements, and study materials through separate Admin and Student portals.

This project was built to understand Java web development concepts such as the MVC architecture, database connectivity using JDBC, session management, and CRUD operations.

▶️ How to Run the Project
Prerequisites
Java JDK 25
Eclipse IDE
Apache Tomcat 11
MySQL Server
Steps
Clone this repository.

Create the MySQL database.

Import the provided SQL files.

Update the database credentials in DBConnection.java.

Import the project into Eclipse.

Configure Apache Tomcat.

Run the project on the server.
